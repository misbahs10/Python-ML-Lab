# 🧠 AI Agents & Multi-Agent Systems

## 🤖 AI Task Agent
A Python-based AI agent that answers questions **and** performs tasks by dynamically choosing and calling tools (calculator, web search, note-saving), using a Reasoning → Action → Observation loop.

**Tech Stack:** Python · Groq API (`openai/gpt-oss-20b`) · Tavily API (web search) · Function Calling

---

## 👥 CrewAI Multi-Agent Systems
A collection of multi-agent AI systems built with CrewAI, where multiple specialized agents collaborate on a task:

- **Multi-Agent System** – Multiple agents (Researcher, Analyst, Writer, Reviewer) working together with custom tools to produce research/report outputs
- **Data Analyst Agent** – Agent-based data analysis workflow producing structured reports from raw data
- **Researcher & Writer Agent** – Two agents collaborating to research a topic and write a polished article

**Tech Stack:** Python · CrewAI · Custom Tools (Research, Calculator, Text Analysis, Report Generation)

---

## 📄 RAG Application — Document Q&A AI
A Retrieval-Augmented Generation app that answers questions grounded in the content of uploaded PDFs, instead of relying only on an LLM's training data. Includes both a CLI and a FastAPI REST API.

**Tech Stack:** LangChain · HuggingFace Embeddings (`sentence-transformers/all-MiniLM-L6-v2`) · ChromaDB · Groq LLM · FastAPI
